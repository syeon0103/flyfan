================================================================================
INSTALLATION & SETUP
================================================================================

PREREQUISITES:
  - Node.js 18.0.0 or higher
  - npm 10.0.0 or higher

STEPS:
  1. Navigate to project:
     cd /tmp/flyfan

  2. Install dependencies:
     npm install

  3. Start development server:
     npm run dev

  4. Open browser to:
     http://localhost:3000

BUILD FOR PRODUCTION:
  npm run build
  npm start

TROUBLESHOOTING:
  If npm install fails with 403 errors:
  - Try: npm install --legacy-peer-deps
  - Or use: yarn install
  - Or manually provide node_modules from another environment
